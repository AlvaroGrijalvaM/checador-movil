   SCRIPT DE INSERTS DE PRUEBA - checador_db

   OBJETIVO:

       Poblar la base de datos (vacía) con datos suficientes
       para probar la Smart TV, verificando que:

           - Solo se muestren empleados con estado = 'RETARDO'

       Jueves    24-sep-2026
       Viernes   25-sep-2026
       Sábado    26-sep-2026
       Domingo   27-sep-2026
       Lunes     28-sep-2026
       Martes    29-sep-2026

   IMPORTANTE:

       1. Este script hace INSERT directos a las tablas
          (empleados, horarios, checadas), NO usa los
          stored procedures, porque los procedures de
          checadas usan NOW() y no permiten "fabricar"
          fechas pasadas/futuras para pruebas.

          PRUEBA (placeholder). NO sirve para iniciar
          sesión real. En producción, Node.js debe generar
          el hash real con bcrypt/Argon2.

          ya se ejecutó el script de creación de tablas y
          procedures, y que las tablas están vacías

              Entrada:     08:00:00
              Salida:      17:00:00
              Tolerancia:  10 minutos

          se considera A_TIEMPO, y después de esa hora es
          RETARDO. Los horarios de prueba están configurados

/* ============================================================
   3. HORARIOS

   Se agrega horario de Lunes a Domingo (1 a 7) para los
   10 empleados, todos con:

       08:00 - 17:00, tolerancia 10 minutos

   Esto cubre cualquier día en el que se generen checadas.
   ============================================================ */

INSERT INTO horarios (id_empleado, dia_semana, hora_entrada, hora_salida, tolerancia_minutos)
SELECT e.id_empleado, d.dia, '08:00:00', '17:00:00', 10
FROM empleados e
CROSS JOIN (
    SELECT 1 AS dia UNION ALL SELECT 2 UNION ALL SELECT 3 UNION ALL
    SELECT 4 UNION ALL SELECT 5 UNION ALL SELECT 6 UNION ALL SELECT 7
) d
WHERE e.id_empleado BETWEEN 1 AND 10;

   5. VERIFICACIÓN RÁPIDA
   ============================================================

   Descomenta para revisar rápidamente que cada día tenga
   al menos 3 RETARDO y 3 A_TIEMPO:

   SELECT
       DATE(fecha_entrada) AS dia,
       estado,
       COUNT(*) AS total
   FROM checadas
   GROUP BY DATE(fecha_entrada), estado
   ORDER BY dia, estado;

   Para probar directamente lo que vería la Smart TV hoy:

   CALL sp_retardos_hoy();

   NOTA: sp_retardos_hoy() y sp_checadas_tv_hoy() usan
   CURDATE(), así que solo mostrarán datos del día en que
   ejecutes la consulta. Si hoy es 24-sep-2026, mostrará los
   10 registros de esa fecha (5 RETARDO). Para ver los demás
   días, usa sp_reporte_fecha(p_id_admin, 'YYYY-MM-DD') con
   un administrador válido, o consulta directamente la tabla
   checadas filtrando por fecha.

   ============================================================ */
